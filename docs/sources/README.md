N -->` comments; cite them in specs ("M guide p. 102"). |

Conventions in the M guide transcription: optional syntax elements are printed in double square brackets and kept as `[[ ]]`; the manual's own errors are reproduced and marked `[sic]`; `[?]` marks a doubtful reading; `[Note: …]` lines are the transcriber's. The table of contents and the index are omitted.
